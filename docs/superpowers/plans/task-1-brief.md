# Task 1: Security - Remove Secrets from Git

## Task Description

Remove hardcoded secrets from git tracking and create a template configuration file.

## Files to Modify

- Modify: `.gitignore`
- Create: `config.yaml.example`
- Modify: `README.md`

## Steps

1. Add `config.yaml` to `.gitignore`
2. Create `config.yaml.example` with placeholder values
3. Verify `.gitignore` works
4. Commit changes

## Expected Output

- `config.yaml` is ignored by git
- `config.yaml.example` contains placeholder values (YOUR_API_ID, YOUR_API_HASH, etc.)
- README updated with setup instructions

## Constraints

- Do not modify existing `config.yaml` (it stays as-is for local use)
- Keep all placeholder values clearly labeled
- Maintain existing README structure
